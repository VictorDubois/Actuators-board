Compact ESP32-based PCB, to control:
- 2 steppers
- 8 hobby servomotors (dedicated 6V DC-DC)
- AX12 Dynamixel numeric servomotors
- Addressable LEDs
- 2 vaccum sensors
- 4 generic GPIO connectors
- 3 generic I2C connectors
- 2 Krabi-Bus (12V/12V power/24V power/CAN)

[The code is available here](https://github.com/VictorDubois/ActuatorBoardCode)
